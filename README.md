## The pitch

> I've delivered 214 crumbs to the same bench for nine years — zero churn, zero burn, and my only investor still thinks I'm a statue.

One line, 131 characters: the elevator pitch a city pigeon gives to investors
for its startup — first-person pigeon voice, one concrete track record
(214 crumbs, nine years), startup vocabulary (churn, burn, investor),
and a twist at the end.

## How it works

`main.py` writes the pitch to `/output/entry.txt` (UTF-8, 1–200 characters,
no trailing newline). Run it with `python3 main.py`. The output is
deterministic: two runs produce the identical file (same sha256).
